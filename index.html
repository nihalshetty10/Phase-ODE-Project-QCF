Neural ODE trading experiment on SPY

I trained a small Neural ODE to predict the next daily return of SPY and compared it with an LSTM, a linear autoregression, buy-and-hold, and cash.

Result. The Neural ODE made money in the 2023–2024 test period, but it did not beat buy-and-hold. Its smaller drawdown came with much lower market exposure. The page below is generated from the checked-in backtest output.

Models

Neural ODE. The input is a 20-day window of standardized log returns. A linear layer maps the window to a 16-dimensional state. A learned vector field evolves that state from 0 to 1 using four RK4 steps, followed by a linear next-return forecast.

LSTM. One recurrent layer with 16 hidden units, trained on the same inputs and target.

Ridge AR(20). A regularized linear forecast using the same 20 lagged returns. The regularization parameter is selected on validation error.

Each forecasting model maps its prediction to a long, short, or cash position. The neutral threshold is selected on 2022 validation Sharpe. A one-way position change costs 5 basis points.

Limitations

This is one ETF and one two-year test period. The simulation does not include bid-ask spread, market impact, financing, short-borrow constraints, or taxes. The fixed transaction charge is only an approximation. The strong SPY market in 2023–2024 also makes this a favorable period for buy-and-hold. These results are descriptive, not evidence that the model will generalize.
