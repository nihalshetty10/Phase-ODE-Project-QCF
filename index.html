EXPERIMENT DESIGN

Built to be challenged

The point is not to manufacture an impressive equity curve. It is to make the test legible, repeatable, and difficult to accidentally contaminate.

TRAIN—

Fit model parameters and return scalers using trailing 20-session log returns.

VALIDATE—

Choose early stopping and a neutral-zone threshold. No test observations are used.

TEST—

Freeze the setup and evaluate one-step forecasts with 5 bps per position change.

A

Neural ODE

A 20-return window is encoded into a 16-dimensional latent state. A learned vector field is integrated from t=0 to t=1 with four differentiable RK4 steps before the next return is read out.

B

LSTM

A single-layer, 16-unit recurrent network consumes the same normalized return window and predicts the same one-session target.

C

Ridge AR(20)

A regularized linear model tests whether either neural architecture adds value beyond a simple autoregressive forecast.

D

Passive controls

Buy-and-hold measures the opportunity cost of trading; cash makes it obvious when a model’s apparent risk control is just non-participation.

Important limitations

This is one instrument and one two-year market regime. Threshold selection uses a single validation year, costs omit spread and market impact, dividends are represented only through adjusted prices, and no statistical significance claim is made. A credible next step is rolling walk-forward retraining across multiple assets and regimes.
